# Requisitos Não Funcionais

## RNF001
Tempo máximo de resposta: 5 segundos.

## RNF002
Disponibilidade mínima de 99%.

## RNF003
Todas as mensagens devem ser registradas.

## RNF004
Backup diário.

## RNF005
A comunicação deverá utilizar HTTPS.

## RNF006
Somente usuários autenticados poderão acessar o painel.

## RNF007
O sistema deverá suportar múltiplas empresas (multiempresa).

## RNF008
As credenciais deverão ser armazenadas com segurança.

## RNF009
O sistema deverá registrar logs de erro.

## RNF010
O sistema deverá ser compatível com dispositivos móveis.
