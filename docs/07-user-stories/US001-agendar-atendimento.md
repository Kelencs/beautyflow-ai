# US001 – Agendar Atendimento

## Como

Cliente

## Quero

Agendar um horário pelo WhatsApp.

## Para

Reservar um atendimento sem precisar ligar para o salão.

---

## Prioridade

Alta

---

## Caso de Uso Relacionado

UC001

---

## Critérios de Aceite

- O sistema deve consultar o Google Calendar.
- O sistema deve oferecer apenas horários disponíveis.
- O sistema deve criar o evento automaticamente.
- O sistema deve enviar a confirmação.
