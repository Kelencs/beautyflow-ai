# UC016 — Reengajar Cliente Inativo

**Status:** Parcial  
**Ator principal:** Sistema/Proprietário

## Rastreabilidade
- RF: RF024
- RN: RN037, RN055–RN061
- Implementação: Chamador→WF015→WF012

## Fluxo principal
1. seleciona cliente autorizado.
2. deriva último atendimento.
3. bloqueia futuro.
4. calcula tentativa.
5. envia/registra.

## Alternativas/observações
- máx 2 por ciclo.
- consentimento deve ser real.
