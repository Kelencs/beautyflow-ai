# Definition of Done

- código/workflow versionado;
- lint/build/test aplicáveis passam;
- CT atualizado;
- evidência registrada;
- logs/erro tratados;
- segurança/segredos revisados;
- documentação e rastreabilidade atualizadas;
- sem gap crítico oculto;
- integração externa validada ou marcada explicitamente como pendente.
