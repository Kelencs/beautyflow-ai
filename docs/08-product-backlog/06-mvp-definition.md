# Definição do MVP

## MVP de automação
- WhatsApp/IA;
- agenda;
- clientes;
- pagamento/cobrança;
- comunicações;
- administração;
- logs e testes essenciais.

## MVP do App
Não é sinônimo do MVP n8n.

Mínimo proposto:
- autenticação;
- empresa/usuários;
- agenda;
- clientes;
- profissionais/serviços;
- financeiro básico;
- gateway n8n;
- auditoria.

## Não obrigatório no primeiro App
- BI avançado;
- lista de espera;
- campanhas;
- pagamentos integrados;
- app mobile nativo.
