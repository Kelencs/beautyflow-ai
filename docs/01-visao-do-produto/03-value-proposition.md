# Value Proposition

## Para o negócio
- menos atendimento manual;
- agenda mais organizada;
- registro financeiro operacional;
- comunicação padronizada;
- recuperação de clientes inativos;
- rastreabilidade técnica.

## Para o cliente final
- atendimento pelo WhatsApp;
- consulta de disponibilidade;
- agendamento, reagendamento e cancelamento;
- confirmação e lembretes;
- pesquisa pós-atendimento.

## Para o profissional
O App planejado centraliza agenda, clientes, serviços, financeiro e comunicações, usando os workflows como camada de regra operacional.

## Diferencial
O BeautyFlow não trata IA como fonte absoluta de dados: informações dinâmicas devem vir das ferramentas e fontes oficiais do negócio.
