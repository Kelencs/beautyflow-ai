# Evidências de Testes

Esta pasta preserva o histórico das execuções de teste.

## Regra de versionamento

Relatórios datados são imutáveis: não reescrever um relatório antigo para fazê-lo parecer atual. Quando o status mudar, criar um novo consolidado.

## Evidência mínima recomendada

- workflow/caso;
- data/hora;
- cenário;
- dados sintéticos;
- execution ID;
- resultado esperado;
- resultado observado;
- print/log quando necessário;
- correção aplicada, se houve;
- resultado da regressão.
