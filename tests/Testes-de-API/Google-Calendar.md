# Teste — Google Calendar

## Workflows
WF004, WF005, WF006 e WF007.

## Cenários
- consultar eventos;
- criar evento;
- atualizar evento conforme configuração atual;
- cancelar/excluir ou refletir cancelamento conforme fluxo;
- erro de credencial;
- calendário incorreto;
- conflito/ocupação.

## Atenção
Confirmar o calendário selecionado no ambiente de teste antes de executar efeitos de escrita.
